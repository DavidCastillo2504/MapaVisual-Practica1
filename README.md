# Mapa Visual ITIL — React + JSX

Frontend interactivo hecho con React + Vite.

## Requisitos

- Node.js 18 o superior
- npm

## Ejecutar

Abre una terminal dentro de la carpeta y ejecuta:

```bash
npm install
npm run dev
```

Después abre la dirección que muestra Vite, normalmente:

```text
http://localhost:5173
```

## Temas incluidos

- Fundamentos y Estrategia del Servicio
- Diseño del Servicio
- Seguridad, Continuidad y Disponibilidad
- Transición del Servicio

Haz clic en cualquiera de los cuatro bloques para mostrar sus conceptos principales.
